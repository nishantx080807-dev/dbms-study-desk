# Study Desk is open to everyone

Visit **https://dbms-study-desk.vercel.app/**. No account, invitation, payment or sign-in is required to study. Share this same link with classmates.

1. Browse any of the 13 chapters. The suggested learning path does not restrict access.
2. Read the lesson, explore the interactive lab, and try the chapter quiz or recall cards.
3. Check a task only after doing the work. Use notes and review flags to track gaps.
4. Progress saving starts **off, session only**. Enable it to keep progress on the current browser/device.
5. Download a progress backup from **Data** to move your work to another device. Restore it there after reviewing the confirmation.

Each visitor has their own progress. Your checklist and notes are not shared with Nishant or other students. There is no automatic account or cloud synchronization.

Lessons, quizzes and labs work offline after the app has completed its first download. External videos and resource links need internet. The SQL lab uses SQLite; Oracle and MongoDB examples in the handbook remain study material.

Source code and run instructions: https://github.com/nishantx080807-dev/dbms-study-desk
